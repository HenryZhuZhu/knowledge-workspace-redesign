# 知识工作台 · 界面 Redesign

对一个企业级「知识库 + 项目协作 + 任务 + AI 助手」工作台首页的重设计。
原始界面见 [`index.JPG`](./%20index.JPG),交互 Demo 见 [`index.html`](./index.html)(双击用浏览器打开即可)。

## 原界面主要问题
1. **视觉层级失衡** —— 顶部 4 个大入口卡权重均等、占据黄金视区,挤压真正消费的内容。
2. **无视觉焦点** —— Banner、大卡、密集网格同时争夺注意力。
3. **内容卡片过密、可扫描性差** —— 卡片小、间距挤、标题重复。
4. **色彩系统混乱** —— 红/蓝/橙多强调色无规则并用。
5. **右侧告警/任务栏低效** —— 条目重复、对比度低、信息挤压。
6. **左侧导航过载** —— 图标多、无分组、认知成本高。
7. 排版层级弱、留白不均、缺少交互态。

## Redesign 关键改动
| 改动 | 理由 | 收益 |
|---|---|---|
| 4 大入口 → 紧凑快捷入口条 | 入口是通道而非内容 | 首屏内容可见量 ↑ |
| 强化全局搜索 + 工作台问候/概览 | 给用户明确落点 | 缩短查找路径 |
| 统一卡片 + 网格/列表切换 + 标签筛选 | 一致性 + 场景化密度 | 定位速度 ↑ |
| 色彩收敛为「1 主色 + 语义色」 | 主色=操作,语义色=状态 | 更专业、更易读 |
| 右侧栏重构为清晰任务卡 | 状态/负责人/时间分层 | 可读性、处理效率 ↑ |
| 导航分组 + 选中态 + 折叠 | 结构化降低认知负荷 | 导航效率 ↑ |
| 建立字阶 + 8px 栅格 + 全交互态 | 节奏与反馈 | 精致度、操作信心 ↑ |

## 版本迭代
通过 git / GitHub 管理,见提交历史。

### v2 · 默认内容从「推荐」改为「我的工作流」
**背景(用户访谈)**:用户抱怨"乱、找不到东西"。根因是中间区默认展示**推荐**内容——
这是消费型/lean-back 模式,而知识工具的核心任务是**接着上次干活**(生产型/lean-forward);
推荐内容位置随刷新变化,破坏空间记忆,导致"找不到"。

**改动**:
- ⏩ **继续编辑(Jump back in)**:横排展示我最近编辑的 4 篇,带"上次编辑 · 时间",一键继续。
- 📌 **置顶 · 常用**:可 Pin 高频文档,**位置固定不变**,直接解决"找不到"(空间稳定性);本地持久化。
- 🔀 **Tab 重排**:`最近编辑 · 我创建的 · 我收藏的 · 推荐`,推荐降级为最后一个 Tab(opt-in)。
- 🧭 **默认 = 最近编辑**,并**记住上次停留的 Tab**(localStorage),尊重个人习惯。
- 卡片元信息由"浏览量"改为"**上次编辑时间**",更贴合"找回自己的东西"。

**设计原理**:默认服务 80% 高频路径 · 识别优于回忆(recognition>recall) · 空间稳定性 · 任务可快速恢复(resumption)。

### v3 · 消除冗余 + 删除重复入口 + 补齐协作场景
**背景**:对 v2 的批判性复盘发现两处问题——

1. **「继续编辑」与「最近编辑」冗余**:二者都按编辑时间排序,我最近改的文档在首屏上下出现两次,反而制造"乱"。
   → **区分语义**:横排「继续编辑」= 我最近**编辑**的(authoring,一键继续);默认列表改为「**最近访问**」= 我打开过的全部(含只读浏览),是个超集。编辑 ≠ 访问,不再重复。
2. **首页功能入口卡与左侧导航重复**:Skills/项目/应用/知识库在左侧导航已有,首页再放一遍只是占用首屏黄金位(正是 index.JPG 的原问题)。
   → **删除入口卡**,首屏让位给"我的工作"内容;导航统一交给左侧;概览仅保留一条统计条。

**其他**:
- 🤝 新增「**分享给我**」Tab(同事分享 / @我)——补齐跨人协作的"别人给我的找不到"场景。
- Tab:`最近访问 · 我创建的 · 收藏 · 分享给我 · 推荐`;默认「最近访问」并记忆上次停留。
- 「推荐」收敛为"你可能想看、但**还没打开过**"的真发现内容(与"我访问过的"互斥)。

**原则一句话**:首页 = 我的工作台(找回 + 待办),不是功能启动器;导航的事交给导航。

### v4 · 以「项目」为组织主轴 + 拆出二级页面
**背景**:笔记大多存放在**项目下的目录/子目录**里,用户需要"我有多少个项目""按项目找到笔记"。据此调整 IA:

- ➖ **精简首页**:去掉「继续编辑」横排、「收藏」「分享给我」Tab;文档列表只留 `最近访问 · 我创建的`。
- 📂 **新增「我的项目」区**:首页展示项目卡(笔记数 / 目录 / 成员 / 进度),概览统计含"我的项目 6 个"。
- 🧭 **文档卡显示 `项目 › 目录` 面包屑** + **按项目筛选 chips**:直接回答"不同项目下的笔记怎么找"。
- 🗂️ **新增「项目管理」二级页**(左侧导航「项目」进入):所有项目集中管理。
- 🔭 **统一「发现 = 推荐」**:推荐内容从首页 Tab 移到独立的**「发现」二级页**(左侧导航「发现」进入),收敛为"还没打开过、可能想看"的内容;首页不再有推荐。
- ➖ 左侧导航**去掉「消息」**。

**技术**:单文件内用轻量路由 `go(page)` 切换 `首页 / 项目管理 / 发现` 三个 `.page`;`PROJECTS` 为新的一级数据,`DOCS` 增加 `project`/`dir` 归属字段。

### v5 · 任务/告警多应用分类 + 视觉升级(Light/Dark)
1. **任务/告警将通过 API 开放给各应用 → 需要妥善分类管理**:
   - 每条任务/告警标注 **来源应用**(项目管理 / CI/CD / 文档系统 / 审批流 / 监控)。
   - 顶部 **按来源筛选 chips**(全部来源 + 各应用 + 数量),解决"多来源混在一起"。
   - 列表 **分组**:任务按状态(进行中/待办/已完成),告警按严重度(严重/警告/提示),组头带计数。
   - 数据结构 `FEED` + `SOURCES` + `GROUPS`,新应用接入只需加来源,渲染自动归类。
2. **首页文档 Tab**:`我创建的` → **`推荐`**(`最近访问 · 推荐`)。
3. **视觉整体升级**:
   - 配色收敛为**克制靛蓝主色 + 冷调石板灰中性 + 低饱和语义色**;发丝边框、极轻分层阴影,Dashboard 耐看高级。
   - 文档封面从彩色 emoji 块改为**同色系低透明度淡色**(`accent + 1a`),Light/Dark 都自然。
   - **Light / Dark 双主题**:完整 token 覆写;**记忆选择(localStorage)+ 首次跟随系统**偏好。
